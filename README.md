# 绝区零桌面电量 (ZZZBattery)

一款专为《绝区零》绳匠打造的 Windows 原生桌面电量与便笺小组件。

无需额外配置复杂环境，自带独立运行库，解压即用。帮助您在电脑桌面上实时掌握电量恢复进度、一键完成每日签到、追踪日常待办与活动进度。

---

## ✨ 核心功能

* ⚡ **实时电量与恢复推算**：实时计算当前电量数值与完全回满倒计时，支持电量回满系统通知提醒。
* 🎁 **一键米游社每日签到**：小组件上一键为当前角色打卡米游社每日福利，自动防重复、防漏签。
* 📋 **全方位便笺追踪**：日常活跃度、刮刮卡、录像店营业收益、丽都周纪经验、恶名狩猎与限时活动进度清晰呈现。
* 🎨 **全角色精美立绘壁纸**：内置绝区零全角色专属壁纸与主题配色，随心切换心仪代理人。
* 🎛️ **三种显示形态**：支持【精美角色卡】、【紧凑面板】与【极简迷你条】，满足不同桌面布局需求。
* 🖥️ **多屏与高分屏自适应**：原生适配 1080P / 2K / 4K 及不同系统缩放比例，具备智能位置记忆与开机恢复能力。

## 🚀 快速上手

### 1. 下载与运行
1. 前往 [Releases 页面](https://github.com/met-tk/ZZZBattery/releases) 下载最新版本的压缩包（如 `ZZZBattery-1.2.9-win-x64.zip`）；
2. 解压到您喜欢的任意文件夹；
3. 双击运行 **`ZZZBattery.exe`** 即可启动。

### 2. 绑定游戏角色
1. 启动后点击小工具下方的 **设置齿轮**，切换到 **账号** 分页（或直接在引导窗口中操作）；
2. 点击 **扫码连接**，使用手机端“米游社 App”扫描二维码并确认授权；
3. 在角色列表中选择您当前游玩的角色，点击 **使用此角色**，便笺数据即会自动同步到桌面。

## 🎮 常用操作指南

| 操作 | 功能说明 |
| :--- | :--- |
| **拖动窗口** | 鼠标按住角色立绘或标题栏区域即可随意拖动，靠近屏幕边缘自动贴边吸附 |
| **切换形态** | 点击界面上的缩小 / 展开图标，可在角色卡与极简迷你电量条之间快速切换 |
| **更换壁纸** | 点击角色卡上的专属齿轮图标，挑选全角色立绘壁纸与主题风格 |
| **一键签到** | 点击角色卡顶部的 **今日签到** 按钮，直接完成当日米游社社区签到 |
| **展开便笺** | 点击 **全部便笺 / 今日便笺**，按日常、每周、经营、活动分类查看详细进度 |
| **桌面设置** | 点击下方工具栏齿轮，自由调整开机自启动、电量回满提醒、显示模式与外观 |
| **系统托盘** | 单击托盘图标快速显隐小组件；右键托盘图标可手动刷新、找回窗口或退出程序 |

## 🔒 隐私与数据安全

* **本地加密**：您的登录凭据使用 Windows 原生 DPAPI（数据保护 API）仅在您的个人电脑本地加密保存，其他软件与用户无法窃取。
* **纯净无后台**：程序不设任何第三方中转服务器，直接与官方服务通信，绝不收集、上传任何玩家账号隐私或设备数据。

## 💻 系统需求

* **操作系统**：Windows 10 / Windows 11 (64位)
* **环境依赖**：系统需具备 Microsoft Edge WebView2 运行时（Windows 10/11 系统通常已默认预装）
