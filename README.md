# 绝区零桌面电量 1.2.6

Windows 原生小组件：电量恢复估算、日常便笺、每周进度、经营状态与官方小组件活动。支持角色主题、迷你条、系统托盘和回满提醒。

## 运行与更新

运行 `dist/ZZZBattery-1.2.6/ZZZBattery.exe`，或解压 `dist/ZZZBattery-1.2.6-win-x64.zip` 后运行。发布版自带 .NET 运行时，适用于 Windows 10 / 11 x64。

更新时先从托盘退出旧版，再启动新版。沿用 `%LOCALAPPDATA%\ZZZBattery` 下的加密账号和外观设置；旧版便笺缓存显示“待同步”，成功刷新后恢复准确状态。本次源码修改位于“电量监测 - 副本”工作区。

## 1.2.6 验证与同步结果

- **没有验证码也有明确结果**：原“完成电量验证”入口改名为“恢复电量同步”。窗口说明仅在官方要求时才会出现验证码；若网页已能显示电量，无需继续寻找验证码。加入“检查同步”按钮，正常冷却仍然生效，不因打开网页而清空。
- **真实便笺立即更新**：收到官方便笺接口的成功响应并确认与当前角色一致后，直接应用数据，不先追加访问可能仍受限的小组件接口。说明数据来自网页，补充活动以之后的小组件查询为准，不宣称所有接口均已解除验证。
- **普通同步恢复也能结束等待**：窗口打开后，只要当前账号、角色取得新的成功数据，即显示同步恢复并自动关闭。旧缓存、清除错误状态、错误角色、缺失数据、失败响应均不能触发成功。
- **角色定位与诊断**：角色参数放在官方单页路由读取的位置；响应读取失败、角色不匹配和接口错误给出具体提示。诊断只保存时间、结果类别和错误码，不记录登录资料、角色标识或响应原文。

## 1.2.5 设置界面（保留）

- **四个分页**：外观、桌面、提醒、账号分别管理；固定顶部导航和底部保存提示。默认尺寸完整显示各页，较小窗口保留细滚动条，可调整窗口大小。
- **显示方式卡片**：角色卡片、简洁面板、迷你电量条直接选择；迷你模式保留之前的完整布局，方便从托盘恢复。
- **统一外观**：圆角分组、清晰的标题与说明、滑动开关，以及随深浅主题和强调色变化的下拉框。游戏路径显示文件名，悬停查看完整路径。
- **即时保存**：修改后立即应用并显示保存结果；保存失败时明确提示。关闭提醒时禁用提前时间选择，保留已选分钟数。开关支持鼠标、键盘和辅助功能操作。
- **沿用原设置**：账号、壁纸、窗口行为和提醒继续使用原有设置文件。可用 `--settings` 启动并直接打开设置。

## 1.2.4 验证窗口与滚动条（保留）

- **空白验证页**：移除内嵌浏览器错误携带的米游社 App 标识，使用真实 WebView2 浏览器身份和官方浏览器入口。原标识会让官方页面等待桌面环境中不存在的 App 接口；对照检查已复现空白并确认修复后正常显示官方页面。
- **加载过程可见**：显示加载进度；导航失败或正文约 20 秒仍未显示时，给出重载、快速验证码和系统浏览器入口。HTTP 200 不再直接视为页面已显示。验证码获取失败时不会自动循环重试。
- **登录与布局**：保留官方登录弹窗的回调；网页区域按手机页面比例适配，避免较矮窗口裁掉登录按钮。只有所选角色的真实数据成功同步才会提示验证完成。若官方页面需要网页登录，请在页面中完成；程序不会将扫码凭据伪装成网页凭据。
- **避免多余验证**：当前没有待处理的验证错误时，托盘入口显示无需验证的提示，不额外打开验证码页。
- **细圆角滚动条**：便笺、外层小组件、设置和扫码窗口使用 10 像素宽轨道、6 像素圆角滑块，移除系统白色箭头和粗边框。随深浅主题调整颜色，悬停或拖动时加深；保留拖动、滚轮和短屏滚动。

## 1.2.3 同步稳定性（保留）

- **小组件优先**：扫码连接且角色归属明确时，直接读取官方小组件。成功后不再额外访问网页便笺，消除旧版“每次先触发网页 10035，再读取小组件”的重复请求。多个角色仍使用明确绑定所选角色的便笺接口，防止串号。
- **受限后停止追加请求**：小组件拒绝查询时保留真实缓存，不自动轮换接口或获取验证码。网络失败按 1、2、5、15 分钟退避；登录、验证或权限错误暂停自动同步，手动再查询至少间隔 15 分钟。服务器指定冷却时按其等待时间处理。
- **重启保留冷却**：保存下次同步、最短刷新间隔、连续失败次数及验证暂停状态。重启、重复点击刷新、系统休眠唤醒和系统时间调整不会清空请求间隔。已有近期数据时直接显示缓存，等待计划同步。
- **固定设备标识**：首次启动在联网前保存设备标识，后续沿用；不通过随机更换设备标识尝试规避验证。
- **30001 单独处理**：验证码创建接口返回 30001 表示当前没有需要完成的验证码，不再误提示重新登录，也不视为已经验证通过；停止自动回退和反复获取。此含义只应用于验证码创建接口，其他接口的同码响应仍保留为异常。快速验证码请求最短间隔 60 秒，切换模式或重开窗口不能缩短同一进程内的间隔。
- **来源准确**：面板显示数据来自官方小组件或实时便笺。小组件成功时不再误报“实时便笺已同步、活动暂缺”。

2026-10-20 使用已连接账号核对：角色绑定 1 次、小组件 1 次、网页便笺 0 次、验证码接口 0 次，成功取得 7 条便笺；模拟重启并立即手动刷新没有增加请求。这是本次实际验证结果，不是长期免验证承诺。第三方客户端无法保证服务端永远不要求本人验证；已经过期的缓存会明确标记，不冒充实时状态。

## 界面与数据修复（保留 1.2.2 功能）

- **状态判断**：按 `cafe_state`、`card_sign`、`vhs_sale.sale_state` 的真实枚举判断。咖啡、刮刮卡不再因读取了错误字段而失踪。录像店 `SaleStateDone` 显示“收益待领取”；正在营业显示进行中，不冒充任务完成。社区签到和游戏内刮刮卡分别处理。
- **数据完整性**：`note_list` 不再排斥结构化日常字段。支持丽都周纪积分、两代悬赏字段、调查点数、随便观收益/制作/售卖/邦布游历/自动经营、会员每日奖励；活动列表与服务端便笺支持惊喜放映企划、丽都周纪等服务端实际返回的项目。
- **桌面信息面板**：卡片每页三项，手动翻页，待办优先；展开全部便笺后可按全部、待办、日常、每周、经营、活动筛选。显示进度条、活动菲林进度、刷新或结束时间、数据来源和同步时间。
- **数据时效**：日常状态不随电量估算而更新。跨国服凌晨 04:00、到达项目刷新时间、同步失败、时间异常或便笺超过 30 分钟时标为待同步；旧值留在详情。电量最多估算两小时，登录失效或时间异常时冻结，移除原先验证码期间可能连续推算 24 小时的行为。
- **账号隔离**：验证窗口只接收精确匹配所选角色、区服和便笺接口的响应。切换账号不再等待旧请求结束，旧响应不能覆盖新账号或已验证的数据。拒绝混合不同账号 ID 的 Cookie。
- **扫码连接**：账号窗口提供米游社 App 扫码入口，获取小组件所需登录凭据并按需换取网页便笺凭据；二维码在本机生成，关闭窗口停止轮询。官方小组件返回有效电量且角色归属明确时使用该数据并显示来源。
- **活动缺失根因**：小组件请求使用的旧客户端版本会让服务端隐藏 `activity_list`，即使接口返回成功。已更新请求版本和客户端标识，并实测取回“惊喜放映企划”等活动。名称统一使用官方的“饼铺盲盒/刮刮卡/占卜”，合并同名服务端便笺，避免重复显示为活动。
- **绘制**：底部使用一块圆角表面，修复两侧背景漏出；电量、活跃度与状态图标分行排布；状态附文字与提示，不依赖颜色；支持短屏幕滚动与卡片等比缩放，避免右边被裁切。

## 哪些信息需要额外登录

实时便笺与手机小组件使用不同的数据接口和登录凭据。普通网页登录可以读取所选角色的电量、刮刮卡、录像店、周纪和经营等便笺；咖啡和活动等补充字段以服务端实际返回为准。

官方 `WV_V2` 小组件接口使用 App 的 `stoken / stuid / mid` 凭据。仅有网页 Cookie 时不会自动获得这部分权限。推荐在“设置 → 连接 / 切换账号 → 扫码连接（推荐）”中，用本人米游社 App 扫描并确认，然后选择角色。也支持手动导入本人已有的完整凭据。不要把 Cookie 发到聊天或日志。程序使用 Windows DPAPI 加密保存。

小组件接口可能选用账号默认角色。为避免串号，仅当角色绑定接口确认此账号只有一个匹配角色时合并补充数据；多个角色时仍显示明确绑定所选角色的实时便笺。接口拒绝、权限不足或活动未返回时会显示具体原因，不编造完成状态、活动或进度。活动数据缺失时“活动”分类会明确说明。

已由用户在手机确认扫码，并用真实账号成功取得官方小组件的日常、周纪积分、悬赏及“惊喜放映企划”活动数据，核对了完成状态和菲林奖励进度。1.2.2 核对时网页实时便笺返回 `10035`；1.2.3 正常同步不再访问这条网页接口。网页接口独有而当前未取得的项目不会伪造。支持某类字段不等于所有账号都会返回该字段。

## 连接与验证

1. 点击“连接米游社 → 扫码连接（推荐）”，用本人米游社 App 扫码并确认。
2. 扫码成功后自动读取角色，选择角色后点击“使用此角色”。也可使用内嵌网页登录，然后点击“读取游戏角色”；此方式可能缺少活动数据。
3. 若查询受限，点击“恢复电量同步”。官方网页出现登录或验证码时，由本人按提示完成；已能看到电量且没有验证提示时，无需额外寻找验证码。匹配所选角色的便笺响应成功后立即同步，窗口在 3 秒后关闭；若仍未同步，可点击“检查同步”查看结果和冷却提示。

需要 Microsoft Edge WebView2 Runtime；缺少时安装[微软官方运行时](https://developer.microsoft.com/microsoft-edge/webview2/)。验证是否成功以官方实际响应为准，不保证所有风控都能通过。10041、5003 与登录失效分别提示。

目前支持米游社国服，不支持 HoYoLAB 国际服。网页登录使用程序独立的 InPrivate 会话，不读取其他浏览器资料，不自动修改便笺权限。

## 使用

| 操作 | 功能 |
| --- | --- |
| 拖动角色图或标题区域 | 移动窗口，靠边吸附 |
| 刷新 | 正常同步最短间隔 60 秒，失败时遵守相应冷却 |
| 卡片底部左右箭头 | 翻页查看三项摘要 |
| 全部便笺 / 今日便笺 | 展开或收起分类列表 |
| 悬停状态图标或便笺 | 完整名称、状态、来源、旧值和时间说明 |
| 角色卡齿轮 | 角色主题壁纸 |
| 下方工具栏齿轮 | 桌面设置、账号、游戏路径和提醒 |
| 缩小 / 展开 | 切换迷你电量条 |
| 横线、托盘单击 | 隐藏或显示小组件 |
| 托盘右键 | 刷新、设置、找回窗口、解除穿透或退出 |

状态标记：`✓` 已完成；`!` 有明确待办；`•` 正在进行；`?` 未知或接口未提供；`↻` 待同步；`–` 未解锁。

默认每 25～30 分钟同步，国服每日刷新点会提前安排同步；电量每秒在本地更新。游戏内消耗、咖啡与奖励要等下一次服务端同步才会反映，可手动刷新。网络失败保留缓存并退避；登录、验证码和权限错误暂停自动重试。冷却和暂停状态在重启后继续生效，完成本人验证或重新连接后恢复。

开机自启动和提醒默认关闭；穿透在每次启动时解除，避免无法操作。小组件是独立无边框窗口，默认不置顶，不注入 Explorer 桌面层。

## 数据目录

默认 `%LOCALAPPDATA%\ZZZBattery`：`settings.json` 为设置和固定设备标识，`credentials.dpapi` 为当前 Windows 用户可解密的凭据，`snapshot.json` 为最近成功数据，`sync-state.json` 为请求冷却及暂停状态。同步状态不保存 Cookie、验证码凭据或原始响应。退出登录清除凭据、快照、同步状态和提醒记录。不要分享个人数据目录。

## 开发与检查

源码为 `src/ZzzBattery.Core` 和 `src/ZzzBattery.Windows`。需要 .NET 10 SDK；依赖存于项目 `.packages`。

```powershell
dotnet build src/ZzzBattery.Windows/ZzzBattery.Windows.csproj -c Release
dotnet test tests/ZzzBattery.Tests/ZzzBattery.Tests.csproj -c Release
powershell -File scripts/build.ps1 -PackageName ZZZBattery-1.2.4
```

参数：

- `--demo`：明确标识演示数据，绝不作为真实账号的错误回退。
- `--data-dir "绝对目录"`：独立数据目录。
- `--connect`：启动时打开账号连接窗口。
- `--ui-smoke-test --data-dir "独立测试目录"`：离线界面检查，包括状态、分页、分类筛选、100/150/200% 渲染、旧数据、长电量值、短屏幕滚动、细滚动条拖动/滚轮及验证失败提示；生成截图与 `ui-smoke-result.json`。
- `--smoke-test --data-dir "独立测试目录"`：完整发布检查，包括 DPAPI、壁纸、设置、WebView2、登录弹窗、未登录官方验证页的渲染与按钮可见性、空白页超时。禁止使用真实账号数据目录。
