# 绝区零桌面电量 (ZZZBattery)

一款专为《绝区零》绳匠打造的 Windows 原生桌面电量与便笺小组件。

无需额外配置复杂环境，自带独立运行库，解压即用。帮助您在电脑桌面上实时掌握电量恢复进度、一键完成每日签到、追踪日常待办与活动进度。

---

## 核心功能

* **实时电量与恢复推算**：实时计算当前电量数值与完全回满倒计时，支持指定电量及回满 Windows 通知，可选择系统声音、自定义 WAV 提示音或静音。
* **一键米游社每日签到（支持米游签附加联动）**：小组件上一键为当前角色打卡米游社每日福利，并内置 [MiyoQian](MiyoQian/README.md) 独立子目录用于多游戏/社区米游币附加签到；支持随“今日签到”联动执行，也可按需在设置中关闭联动或隐藏状态栏。
* **全方位便笺追踪**：日常活跃度、刮刮卡、录像店营业收益、丽都周纪经验、恶名狩猎与限时活动进度清晰呈现。
* **全角色精美立绘壁纸**：内置绝区零全角色专属壁纸与主题配色，随心切换心仪代理人。
* **三种显示形态**：支持【精美角色卡】、【紧凑面板】与【极简迷你条】，满足不同桌面布局需求。
* **多屏与高分屏自适应**：原生适配 1080P / 2K / 4K 及不同系统缩放比例，具备智能位置记忆与开机恢复能力。
* **静默恢复电量同步**：遇到查询验证时，在后台尝试读取所选角色的官方网页便笺，不弹窗、不抢焦点。成功后继续使用该渠道，减少反复请求受限接口。
* **登录凭据持久化**：凭据使用当前 Windows 用户加密保存，Cookie 轮换会自动合并保存；重启后优先恢复本地会话，减少重复登录和验证。

## 快速上手

### 1. 下载与运行
1. 前往 [Releases 页面](https://github.com/met-tk/ZZZBattery/releases) 下载最新版本的压缩包（如 `ZZZBattery-1.4.4-win-x64.zip`）；
2. 解压到您喜欢的任意文件夹；
3. 双击运行 **`ZZZBattery.exe`** 即可启动。

### 2. 绑定游戏角色
1. 启动后点击小工具下方的 **设置齿轮**，切换到 **账号** 分页（或直接在引导窗口中操作）；
2. 点击 **扫码连接**，使用手机端“米游社 App”扫描二维码并确认授权；
3. 在角色列表中选择您当前游玩的角色，点击 **使用此角色**，便笺数据即会自动同步到桌面。

### 米游签附加签到（可选）

发行包与源码仓库均内置 `MiyoQian/` 独立子目录（不含个人配置与登录凭证），在 **设置 → 账号 → 米游签附加签到** 中可统一管理：

* **联动方式**：可开启“随今日签到同步触发”，点击小组件左侧米游签状态栏（或在设置中点击打开网页）即可跳转到本机 Web 控制台扫码连接账号与调整任务配置。
* **精简界面**：如果习惯只通过“今日签到”同步触发米游签，可勾选 **隐藏桌面组件中的米游签状态栏**，小组件底部将不再占用额外高度。
* **运行前提**：仅使用《绝区零》电量与原有一键签到时无需额外环境；若启用米游签联动，需本机已安装 [uv](https://docs.astral.sh/uv/)（首次启动自动创建 `MiyoQian/.venv`）或已在 `MiyoQian/.venv` 中运行 `uv sync`。

### 指定电量与提示音

进入 **设置 → 提醒**，开启 **指定电量提醒**，输入 1～240 的目标电量（默认 180）。电量从低于目标恢复到目标或更高值时发送一次 Windows 通知；消耗到目标以下后再次达到即可重新提醒。首次开启或修改目标时，已经达到目标不会补发通知；重启保留提醒状态。

**电量回满提醒**可独立开启，保留提前提醒和回满提醒。同一时刻触发的提醒会合并为一条通知。**通知声音**对所有电量提醒生效，可选系统默认、自定义 WAV 或静音，提供 **试听** 和 **发送测试通知**。自定义声音支持不超过 10 MB 的 PCM WAV 文件；请保留所选文件，文件丢失或无法播放时会回退到系统声音。

小组件需保持运行，隐藏到托盘也会提醒；数据异常或过旧时暂停判断。Windows 通知设置或勿扰模式可能阻止通知显示，发送测试通知不会改变正式提醒的去重状态。

## 隐私与数据安全

* **本地加密**：您的登录凭据使用 Windows 原生 DPAPI（数据保护 API）仅在您的个人电脑本地加密保存，限制其他 Windows 用户直接读取；仍需保护当前用户的系统安全。
* **登录会话持久化**：登录页和验证页使用账号隔离的 WebView2 配置文件；验证通过后的短期凭证也使用 DPAPI 加密保存，重启程序后会在有效期内自动恢复。
* **纯净无后台**：程序不设任何第三方中转服务器，直接与官方服务通信，绝不收集、上传任何玩家账号隐私或设备数据。

### 电量查询验证与 10035

后台恢复最多等待 45 秒，只接受官方接口返回的当前角色数据，不会自动拖动滑块或代做验证码。若官方页面能直接读取便笺，或官方校验流程自行通过，则自动同步；开机网络未就绪或浏览器暂不可用时，保留旧数据并按 1、2、5、15 分钟退避重试；登录或校验暂未恢复时，按 15、30、60 分钟退避检查，重启后仍遵守冷却，不会永久停在手动恢复状态。浏览器 Cookie 轮换后自动写回加密凭据，会话 Cookie 按原域、路径及有效期加密保存，并在下次启动恢复。若服务端撤销登录或确实要求人工验证码，仍需在官方页面处理，程序不能保证无限续期。恢复过程不会自动打开系统浏览器、提示对话框或其他应用。

成功后按原有约 25～30 分钟间隔同步，并保留手动刷新冷却、单次请求合并和重启后的退避状态；网页未返回的活动信息仍标为不可用。程序运行期间复用账号隔离的浏览器会话，页面读取结束后立即释放页面及其定时器，退出或切换账号时关闭会话。如果无法保存冷却状态，会先暂停请求并在组件中提示写入权限问题。

这些处理减少无效请求和反复验证提示，不能保证官方风控不再返回 10035，也不能保证所有验证都能静默完成。
