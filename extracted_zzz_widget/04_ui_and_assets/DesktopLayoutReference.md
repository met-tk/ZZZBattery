# 绝区零桌面小组件 UI 布局结构与视觉设计规范

本文档根据米游社 APK 逆向还原出的 `layout_widget_nap.xml`、`layout_widget_nap_left.xml`、`layout_widget_nap_right.xml` 及其包含的切图资源进行系统整理，供 Windows 平台（WPF / Qt / Flutter / Electron）复刻时作为像素级布局参考。

---

## 一、 小组件整体外观与尺寸比例

- **默认宽高比**：约 `2:1` 或 `16:9`（Android 标准小组件为 `300dp x 155dp`）。
- **底色与风格**：
  - 风格：绝区零经典的复古潮酷（Street / Cyberpunk / CRT 显示屏）质感；
  - 核心背景图：`bg_widget_nap_bg.png`（深灰带斜向条纹暗纹 `nap_bg_pattern.png`）；
  - 圆角半径：`12px ~ 16px`；
  - 边框：`1px` 半透明描边（`rgba(255, 255, 255, 0.1)`）。
